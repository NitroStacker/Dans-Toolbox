# CodeManu Free VFX Asset Pack

The PNG sprite sheets in this directory are a curated subset of CodeManu's
Free VFX Asset Pack:

https://opengameart.org/content/free-vfx-asset-pack

Author: CodeManu

License: Creative Commons Zero v1.0 Universal (CC0-1.0)

https://creativecommons.org/publicdomain/zero/1.0/

The original pack includes 22 pixel-art effects at 30 and 60 FPS, individual
frames, GIF previews, and SpriteMancer project files. Dans Toolbox includes
only selected 30 FPS PNG sheets needed by Retro VFX. Filenames encode their
Unity grid layout as `__columnsxrows_`.
